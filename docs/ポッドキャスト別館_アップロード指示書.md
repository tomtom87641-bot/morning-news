# ポッドキャスト「別館」へ音声をアップロードする指示書

別のチャットで作った音声（MP3）を、ポッドキャストの別チャンネル「別館」に1回分として公開するための手順。
正本はリポジトリの `docs/ポッドキャスト別館_アップロード指示書.md`。`G:\マイドライブ\obsidian\1\Claude outputs\` にあるのはそのコピー。

**保存場所**

| | 場所 |
|---|---|
| 正本 | リポジトリの `docs/ポッドキャスト別館_アップロード指示書.md` |
| コピー（渡すときはこちら） | `G:\マイドライブ\obsidian\1\Claude outputs\ポッドキャスト別館_アップロード指示書.md` |

**渡し方**：このファイルを、音声を作ったチャットに添付して、次の一言を添える。`○○` の部分は、その回に合わせて書き換える。

添付の指示書に従って、作った音声を別館にアップしてください。日付キーは 2026-10-03-（英小文字の短い印）、題名は「○○」、説明は「○○」です。

## これは何か

- 「朝のニュース」（毎朝の自動配信）とは**別の番組**。ニュース以外の音声（特別編、読み物、実験など）を、いろいろ置いていく場所。
- 配信先は、朝のニュースと同じ GitHub Pages の中の別フォルダ。購読アドレスも別。
- 音声は、アップロードした瞬間から公開される。

| | 朝のニュース | 別館 |
|---|---|---|
| 購読アドレス | `https://tomtom87641-bot.github.io/morning-news/feed.xml` | `https://tomtom87641-bot.github.io/morning-news/annex/feed.xml` |
| 中身 | 毎朝の自動実行が入れる | この指示書の手順で入れる |
| 一覧に残る数 | 最新7回 | 最新20回（21回目を入れると最古が消える） |

## 先に守ること

1. **配信先は公開リポジトリ。** 音声も原稿も、アドレスを知っていれば誰でも読める。個人情報、組合の内部資料、顧客情報は入れない。
2. **「朝のニュース」には上げない。** 手順の中で `--channel news` を指定しても、スクリプトが止める（毎朝の7回の枠を押し出さないため）。
3. **配信用ブランチ（`claude/feed`）を手で触らない。** 必ず次のコマンドを通す。コマンドが、取り出し・書き換え・コミット・プッシュまでやる。
4. 実在の人物・団体を名指しした作り話は載せない（登場人物が架空なら、冒頭でそう断る）。

## 渡してほしいもの

| 項目 | 内容 |
|---|---|
| 音声 | **MP3**。1ファイル50MB以下を目安にする（GitHub は100MBを超えるファイルを受け付けない）。話し声なら 48〜64kbps・モノラルで足りる（64kbpsなら1時間で約29MB）。MP3にできないときは、アップロードせず中澤さんに相談する |
| 日付キー | 回の名札。`2026-10-03-madamis` のように、**日付、ハイフン、英小文字・数字の短い印**。同じ名札の回があると上書きになる（スクリプトが止めてくれる） |
| 題名 | 購読アプリの一覧に出る題名。日本語でよい |
| 説明 | 回の説明。1〜3行 |
| 原稿（任意） | 読み上げた文章のテキスト。あれば一緒に公開される |

長さ（秒）は、MP3から自動で測る。自分で数える必要はない。

## 手順A：このPCでコマンドを実行できるチャットの場合

リポジトリは `C:\Users\PC\morning-news`。Python と git はこのPCに入っていて、GitHub へのプッシュも通る。

**1. 最新にして、いま何が載っているか見る**

```powershell
cd C:\Users\PC\morning-news
git pull origin main
python -m scripts.upload_special list
```

`list` は、別館に公開中の回を JSON で出す（何もなければ `[]`）。日付キーが重ならないかを、ここで確かめる。

**2. 公開せずに、できあがりだけ確かめる**

```powershell
python -m scripts.upload_special upload `
  --mp3 "音声ファイルのフルパス.mp3" `
  --title "題名" `
  --description "説明" `
  --key 2026-10-03-demo `
  --transcript "原稿のフルパス.txt" `
  --dry-run
```

`--transcript` は原稿があるときだけ付ける。`--dry-run` を付けている間は、何も公開されない。出力の `duration_sec`（再生時間）が、想定と大きくずれていないかを見る。

**3. 公開する**

2. のコマンドから `--dry-run` を外して、同じものを実行する。

終わると、公開側に反映されるのを最大4分待って、次のように出る。

```text
公開側に反映されました。
{
  "channel": "annex",
  "key": "2026-10-03-demo",
  "title": "題名",
  "duration_sec": 1132,
  "commit": "47828ef",
  "pushed": true,
  "feed_url": "https://tomtom87641-bot.github.io/morning-news/annex/feed.xml",
  "audio_url": "https://tomtom87641-bot.github.io/morning-news/annex/episodes/2026-10-03-demo.mp3"
}
```

`"pushed": true` になっていれば公開済み。「公開側の反映は確認できませんでした」と出たときは、公開はできていて、反映の確認だけが取れていない（通常1〜2分かかる。このチャットの環境から公開側に接続できないだけのこともある）。

**4. 中澤さんに報告する**

次の4つを伝える。

- 日付キーと題名
- 再生時間
- 購読アドレス（別館）
- 音声のアドレス（`audio_url`）

## 手順B：コマンドを実行できないチャットの場合

音声を作るところまでを担当して、アップロードは、このPCの Claude Code（リポジトリを持っている側）に頼む。

**1. このフォルダに、3つのファイルを置く**

`G:\マイドライブ\obsidian\1\Claude outputs\ポッドキャスト別館\`

| ファイル名 | 中身 |
|---|---|
| `日付キー.mp3` | 音声（例: `2026-10-03-demo.mp3`） |
| `日付キー.meta.txt` | 題名と説明（下の書式） |
| `日付キー.txt` | 原稿。**なくてもよい** |

`日付キー.meta.txt` の書式。1行目が題名、2行目からが説明。

```text
題名: 特別編　議事は止まらない
説明: マーダーミステリーを六人のエーアイが遊んだ記録。
```

**2. 中澤さんに、次のように伝える**

> 別館に上げる音声を `G:\マイドライブ\obsidian\1\Claude outputs\ポッドキャスト別館\` に置きました。日付キーは 2026-10-03-demo です。Claude Code に「別館に上げて」と頼んでください。

**3. 中澤さんが Claude Code に頼む**

Claude Code は、上のフォルダの `meta.txt` を読んで、手順Aの2〜4を実行する。

## 聞いて確かめる

iPhone の Podcasts アプリで、右上の「＋」→「URLで表示」→ 別館の購読アドレスを貼る。公開から反映まで1〜2分かかる。**最初の1回分を上げてから購読する**と確実（回が1件もない状態で購読できるかは、まだ確かめていない）。

## 取り消す（間違えて上げたとき）

```powershell
cd C:\Users\PC\morning-news
python -m scripts.upload_special remove --key 2026-10-03-demo
```

その回の音声と原稿が、一覧と購読フィードから消える。ほかの回は変わらない。日付キーを間違えると「その回は別館にありません」と出て、何も変わらない。

同じ日付キーで差し替えたいときは、取り消さずに、`upload` に `--replace` を付けて実行する。

## エラーが出たとき

| 出たメッセージ | 意味と対処 |
|---|---|
| `日付キー … は使えません` | 形が違う。`2026-10-03-demo` のように、日付のあとに英小文字・数字をハイフンでつなぐ。大文字・日本語・空白・スラッシュは使えない |
| `日付キー … の回がすでにあります` | 別館にその名札の回がある。別の名札にするか、差し替えるなら `--replace` を付ける |
| `朝のニュース（news）は毎朝の自動実行専用です` | `--channel` に `news` を指定している。外す（既定は別館） |
| `音声ファイルが見つかりません` | `--mp3` のパスが違う。フルパスで、日本語のパスは引用符で囲む |
| `MP3 のフレームが見つかりません` | MP3 ではないか、壊れている。MP3 に作り直す |
| `3回試しても公開できませんでした` | 毎朝の自動実行と重なって、プッシュが通らなかった。少し待って、同じコマンドをもう一度実行する |
| `git … に失敗しました` | 続く文面に原因が出る。認証や接続の問題のときは、中澤さんに伝えて止まる |
