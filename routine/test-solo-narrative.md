これは動作確認です。一人語り（掛け合いなし）の原稿を、聞き手に直接語りかけるような口調にして試します。ニュース・メール・カレンダー・Googleドライブには一切触れないでください。有料の音声ツールは使わないでください。作業ファイルは `$HOME/work/` に置き、リポジトリには書き込まないでください。書き込みは新しいブランチ `claude/solo-narrative-test` だけ。`main` と `claude/feed` には push しないでください。

【手順】

1. `bash scripts/setup_cloud.sh` を実行する（2〜3分）。

2. 次の素材をもとに、一人語りの原稿を書いてください（掛け合いにしない。話者は一人）。

素材：「厚生労働省は、来年度の全国の最低賃金の改定額をまとめた。全国平均は時給千百七十七円で、去年より五十六円の引き上げ。東京都は十月一日から時給千二百八十円になる。地域による差は引き続き課題とされている。近年は毎年のように引き上げられており、働く人の暮らしを支える動きとして注目されている。」

口調について：**聞いている人に、直接語りかけるような書き方にする。** 具体的には：
- 事実を伝える文は、正確に、丁寧語で書く（ここは崩さない）。
- ところどころに、聞き手へ話しかける一言を入れる（例：「〜だと思いませんか」「〜なんですよね」「ちょっと想像してみてください」「気になるところですよね」）。
- 一方的な報道文ではなく、隣で話しているような距離感にする。ただし、なれなれしすぎたり、個人的な決めつけ（聞き手の状況を勝手に想像する発言）は避ける。
- 「さて」「ちなみに」「実は」のような、話し言葉らしいつなぎ言葉を使ってよい。
- 完全なタメ口にはしない。丁寧語は保つ。

原稿の書き方：
- 冒頭は「おはようございます、今日のニュースです。」から始め、最後は「以上、今日のニュースでした。」で締める。
- 全体で三百五十字から四百五十字程度。
- 算用数字とアルファベットは使わない（仮名か漢字で書く）。

原稿を `$HOME/work/narrative.txt` に保存してください。

3. 原稿全体を、Kokoro（`is_phonemes=True`、misakiの日本語G2P）で、声 `jf_alpha`・速度 `1.0` で合成してください（`scripts/chunker.py` の `make_chunks` で分割し、`scripts/audio.py` の `concat_with_pauses` でつなげてよい）。モノラル・48kbpsのmp3にしてください。出力先は `$HOME/work/out/solo_narrative.mp3`。

4. 標準出力に、原稿の全文と、mp3の長さ（秒）・ファイルサイズを日本語で報告してください。

5. `git fetch origin && git checkout -b claude/solo-narrative-test origin/main` を実行し、`solo_narrative.mp3` を `samples/solo_narrative.mp3` としてリポジトリに追加し、`git add samples/solo_narrative.mp3` → `git commit -m "Add narrative-style solo sample"` → `git push -u origin claude/solo-narrative-test` を実行してください。push の結果を報告してください。

証明書の検証を無効にしない。プロキシの設定・認証情報・環境変数の中身を読まない。通信制限を迂回しない。通らなければ、事実とエラーの要点だけを報告して止まってください。
