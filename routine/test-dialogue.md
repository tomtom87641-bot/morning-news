これは動作確認です。掛け合い（対話）形式の音声が、聞きやすくなるかを試します。ニュース・メール・カレンダー・Googleドライブには一切触れないでください。有料の音声ツールは使わないでください。作業ファイルは `$HOME/work/` に置き、リポジトリには書き込まないでください。書き込みは新しいブランチ `claude/dialogue-test` だけ。`main` と `claude/feed` には push しないでください。

【手順】

1. `bash scripts/setup_cloud.sh` を実行する（2〜3分）。

2. 次の1つのニュース素材をもとに、二人の掛け合い形式の台本を、あなた自身の言葉で書いてください（他のニュースは探さなくてよい。この1件だけを使う）。

素材：「厚生労働省は、来年度の全国の最低賃金の改定額をまとめた。全国平均は時給千百七十七円で、去年より五十六円の引き上げ。東京都は十月一日から時給千二百八十円になる。」

台本の書き方：
- 話者は「ミナミ」（進行役、女性の声）と「カケル」（相槌・質問役、男性の声）の二人。
- 形式は `ミナミ：（せりふ）` `カケル：（せりふ）` を交互に、改行で区切って並べる。
- 単なる相槌の往復ではなく、カケルが「それってどのくらい変わるんですか」「なんでそんなに上がったんですか」のように、聞き手が気になる点を質問し、ミナミがそれに答える形にする。世間話や小さな感想（例：「へえ、思ったより大きいですね」）も混ぜて、自然な間を作る。
- 算用数字とアルファベットは使わない（仮名か漢字で書く）。
- 全体で二十から二十五のせりふのやり取り、長さの目安は九十秒から百二十秒程度。
- 冒頭に「ミナミ：おはようございます、今日のニュースです。」を入れ、最後は「ミナミ：以上、今日のニュースでした。」で締める。

台本を `$HOME/work/dialogue.txt` に保存してください。

3. 台本を1行ずつ読み、話者ごとに次の声で合成してください（Kokoro、`is_phonemes=True`、misakiの日本語G2Pで音素化）。
   - ミナミ → 声 `jf_alpha`
   - カケル → 声 `jm_kumo`
   話者の切り替えの前後には、0.2秒の無音を挟んでください（scripts/audio.py の concat_with_pauses が使えます）。全部つなげて、mp3（モノラル、48kbps）にしてください。出力先は `$HOME/work/out/dialogue.mp3`。

4. 標準出力に、台本の全文と、mp3の長さ（秒）・ファイルサイズを日本語で報告してください。

5. `git fetch origin && git checkout -b claude/dialogue-test origin/main` を実行し、`dialogue.mp3` を `samples/dialogue.mp3` としてリポジトリに追加し、`git add samples/dialogue.mp3` → `git commit -m "Add dialogue format sample"` → `git push -u origin claude/dialogue-test` を実行してください。push の結果を報告してください。
