【手順】

1. `bash scripts/setup_cloud.sh` を実行する（2〜3分）。

2. 次の台本を、そのまま `$HOME/work/dialogue.txt` に保存してください（内容は変えない）。

```
ミナミ：おはようございます、今日のニュースです。厚生労働省が、来年度の最低賃金の改定額をまとめました。
カケル：最低賃金というと、あの、時給の下限のことですよね。
ミナミ：そうです。全国平均で見ると、時給千百七十七円になりました。
カケル：それって、去年と比べてどのくらい変わるんですか。
ミナミ：去年より五十六円の引き上げです。
カケル：五十六円ですか。へえ、思ったより大きいですね。
ミナミ：はい、近年の中でも大きめの上げ幅と言われています。
カケル：なんでそんなに上がったんですか。
ミナミ：物価の上昇に、賃金が追いついていない、という指摘が背景にあるようです。
カケル：なるほど、暮らしの負担が増えている分、賃金も見直そうということですね。
ミナミ：ええ、そういう狙いがあります。
カケル：地域によって金額は違うんですか。
ミナミ：はい、都道府県ごとに決まっていて、東京都は特に高くなっています。
カケル：東京はいくらになるんですか。
ミナミ：東京都は十月一日から、時給千二百八十円になります。
カケル：千二百八十円ですか。全国平均よりだいぶ高いですね。
ミナミ：都市部は物価や家賃も高いので、その分の差があるんです。
カケル：なるほど、地域の事情に合わせているんですね。でも、上がるのは働く側にはうれしい一方、雇う側は大変じゃないですか。
ミナミ：そうですね。とくに人手を多く雇っている飲食店や小売のお店では、負担が増えるという声もあります。
カケル：値上げにつながったりもするんでしょうか。
ミナミ：可能性はあります。ただ、賃金が上がれば、消費に回るお金も増えるという見方もあるんです。
カケル：一長一短というか、両方の立場があるわけですね。
ミナミ：働く側にとっても、雇う側にとっても、大きな話題になりそうです。
カケル：しばらくは、この話題が続きそうですね。
ミナミ：以上、今日のニュースでした。
```

3. 同じ台本から、Kokoro（`is_phonemes=True`、misakiの日本語G2P）で、次の2パターンの音声を作ってください。話者の切り替えの前後には0.2秒の無音を挟み（`scripts/audio.py` の `concat_with_pauses`）、それぞれモノラル・48kbpsのmp3にしてください。

- パターンA（`$HOME/work/out/pattern_a.mp3`）：ミナミ＝`jf_alpha`（速度1.0）、カケル＝`jm_kumo`（速度1.15、`kokoro.create` の `speed` 引数）。
- パターンB（`$HOME/work/out/pattern_b.mp3`）：ミナミ＝`jf_alpha`（速度1.0）、カケル＝`jf_tebukuro`（速度1.0）。

4. 標準出力に、各パターンの長さ（秒）とファイルサイズを日本語で報告してください。

5. `git fetch origin && git checkout -b claude/dialogue-test2 origin/main` を実行し、`pattern_a.mp3` と `pattern_b.mp3` を `samples/` にコピーして、`git add samples/pattern_a.mp3 samples/pattern_b.mp3` → `git commit -m "Add voice comparison samples"` → `git push -u origin claude/dialogue-test2` を実行してください。push の結果を報告してください。
