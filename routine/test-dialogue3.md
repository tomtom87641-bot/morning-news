これは動作確認です。掛け合い台本の口調を、少しだけフランクにして試します。ニュース・メール・カレンダー・Googleドライブには一切触れないでください。有料の音声ツールは使わないでください。作業ファイルは `$HOME/work/` に置き、リポジトリには書き込まないでください。書き込みは新しいブランチ `claude/dialogue-test3` だけ。`main` と `claude/feed` には push しないでください。

【声の設定（決定済み）】
- ミナミ（進行役）＝声 `jf_alpha`、速度 `1.0`
- カケル（質問・相槌役）＝声 `jm_kumo`、速度 `1.15`

【手順】

1. `bash scripts/setup_cloud.sh` を実行する（2〜3分）。

2. 次の素材をもとに、二人の掛け合い形式の台本を書いてください。

素材：「厚生労働省は、来年度の全国の最低賃金の改定額をまとめた。全国平均は時給千百七十七円で、去年より五十六円の引き上げ。東京都は十月一日から時給千二百八十円になる。」

口調について：**丁寧語（です・ます調）をベースにしつつ、少しだけくだけた言い方を混ぜる。** 具体的には：
- 相槌や短い反応は、カジュアルにしてよい（例：「なるほどですね」ではなく「なるほどねー」「そうなんだ」「へー」「まじですか」）。
- カケルのせりふは、ミナミより少しくだけていい（例：「〜なんですか」の代わりに「〜なの」「〜ってこと」を時々使う）。
- ただし、完全なタメ口や、丁寧語を全部やめることはしない。ニュースを伝える基本の文（事実を言う部分）は、丁寧語のまま。くだけるのは、相槌・感想・軽い質問の部分だけ。
- 「えっと」「まあ」のような、話し言葉らしい言いよどみも、1〜2回程度なら入れてよい。

台本の書き方：
- 形式は `ミナミ：（せりふ）` `カケル：（せりふ）` を交互に、改行で区切って並べる。
- 全体で二十から二十五のせりふのやり取り、長さの目安は九十秒から百二十秒程度。
- 算用数字とアルファベットは使わない（仮名か漢字で書く）。
- 冒頭に「ミナミ：おはようございます、今日のニュースです。」を入れ、最後は「ミナミ：以上、今日のニュースでした。」で締める。

台本を `$HOME/work/dialogue.txt` に保存してください。

3. 台本を1行ずつ読み、話者ごとに次の声で合成してください（Kokoro、`is_phonemes=True`、misakiの日本語G2Pで音素化）。
   - ミナミ → 声 `jf_alpha`、速度 `1.0`
   - カケル → 声 `jm_kumo`、速度 `1.15`
   話者の切り替えの前後には、0.2秒の無音を挟んでください（scripts/audio.py の concat_with_pauses が使えます）。全部つなげて、mp3（モノラル、48kbps）にしてください。出力先は `$HOME/work/out/dialogue3.mp3`。

4. 標準出力に、台本の全文と、mp3の長さ（秒）・ファイルサイズを日本語で報告してください。

5. `git fetch origin && git checkout -b claude/dialogue-test3 origin/main` を実行し、`dialogue3.mp3` を `samples/dialogue3.mp3` としてリポジトリに追加し、`git add samples/dialogue3.mp3` → `git commit -m "Add slightly casual dialogue sample"` → `git push -u origin claude/dialogue-test3` を実行してください。push の結果を報告してください。
