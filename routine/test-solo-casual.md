これは動作確認です。一人語り（掛け合いなし）の原稿を、少しフランクな口調にして試します。ニュース・メール・カレンダー・Googleドライブには一切触れないでください。有料の音声ツールは使わないでください。作業ファイルは `$HOME/work/` に置き、リポジトリには書き込まないでください。書き込みは新しいブランチ `claude/solo-casual-test` だけ。`main` と `claude/feed` には push しないでください。

【手順】

1. `bash scripts/setup_cloud.sh` を実行する（2〜3分）。

2. 次の素材をもとに、一人語りの原稿を書いてください（掛け合いにしない。話者は一人）。

素材：「厚生労働省は、来年度の全国の最低賃金の改定額をまとめた。全国平均は時給千百七十七円で、去年より五十六円の引き上げ。東京都は十月一日から時給千二百八十円になる。地域による差は引き続き課題とされている。近年は毎年のように引き上げられており、働く人の暮らしを支える動きとして注目されている。」

口調について：**丁寧語（です・ます調）をベースにしつつ、少しだけくだけた言い方を混ぜる。** 具体的には：
- 事実を伝える文は、丁寧語のまま（正確さを保つ）。
- 文と文の間に、聞き手に語りかけるような、軽い一言を時々挟んでよい（例：「ちょっと驚きですよね」「これは大きいです」「なるほど、という感じですね」「じわじわ効いてきそうです」）。
- 「さて」「ちなみに」「ただ」のような、話し言葉らしいつなぎ言葉を使ってよい。
- ただし、完全なタメ口にはしない。原稿全体の基本は丁寧語のまま。

原稿の書き方：
- 冒頭は「おはようございます、今日のニュースです。」から始め、最後は「以上、今日のニュースでした。」で締める。
- 全体で三百五十字から四百五十字程度（掛け合い版と近い長さにする）。
- 算用数字とアルファベットは使わない（仮名か漢字で書く）。

原稿を `$HOME/work/solo.txt` に保存してください。

3. 原稿全体を、Kokoro（`is_phonemes=True`、misakiの日本語G2P）で、声 `jf_alpha`・速度 `1.0` で合成してください（`scripts/chunker.py` の `make_chunks` で分割し、`scripts/audio.py` の `concat_with_pauses` でつなげてよい）。モノラル・48kbpsのmp3にしてください。出力先は `$HOME/work/out/solo_casual.mp3`。

4. 標準出力に、原稿の全文と、mp3の長さ（秒）・ファイルサイズを日本語で報告してください。

5. `git fetch origin && git checkout -b claude/solo-casual-test origin/main` を実行し、`solo_casual.mp3` を `samples/solo_casual.mp3` としてリポジトリに追加し、`git add samples/solo_casual.mp3` → `git commit -m "Add casual solo narration sample"` → `git push -u origin claude/solo-casual-test` を実行してください。push の結果を報告してください。
